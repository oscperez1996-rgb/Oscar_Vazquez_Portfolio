# Oscar Vazquez — Portfolio

Plain HTML + CSS, no build step. Open `index.html` in any browser.

## Files
- `index.html` — home page (hero, projects, contact)
- `about.html` — about me, activities, toolkit
- `projects/` — one page per project (es51, boat, hurc)
- `styles.css` — every style for every page; colors and fonts are at the top under "Design tokens"
- `assets/` — images, named by what they show

## Common edits
- Change a color: edit `--crimson`, `--ink`, etc. at the top of `styles.css`.
- Add a project: copy one `<a class="project-row">` block in `index.html`, and copy a page in `projects/`.
- Unused images ready to add: `servo-cad-1.png`, `servo-cad-2.png`.
